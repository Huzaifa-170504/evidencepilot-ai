# EvidencePilot AI usage guide

## Recruiter mode

1. Open <https://huzaifa-170504.github.io/evidencepilot-ai/>.
2. Select **Try the recruiter demo**.
3. Review or change the Mamba-YOLO question.
4. Choose quick, standard, or deep scope.
5. Start research.
6. Inspect agent activity, sources, claims, report, memory behavior, and Engineering.
7. Export Markdown or print the report to PDF.

**API connected** means the Render backend answered. **Cached demo** means the reproducible browser snapshot is being used while the free backend wakes.

## Authenticated PDF mode

1. Create an account or sign in.
2. Create a research project.
3. Upload a non-sensitive PDF from Documents.
4. Wait for the document to become `ready`.
5. Ask a document-grounded question.
6. Confirm Document Research appears in the selected agents.
7. Inspect filename/page citations.
8. Delete the project or document when finished.

PDFs are limited to 10 MB and 150 pages. The public interface permits two PDFs. Scanned PDFs require future OCR support.

## Recommended recruiter walkthrough

Use the preloaded question, open Sources, compare the three claim verdicts, inspect the referenced report, then open Engineering and the GitHub repository. The complete walkthrough takes approximately three minutes.
